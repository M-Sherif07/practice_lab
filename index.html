Topic 01

Variables

A variable is a name that refers to a value. Think of a labelled box: you put a value in with = and use the label later.

  • length = 10stores 10 in a box called length
  • a + breads both boxes and adds them
  • sleep(1000)waits 1000 ms, which is 1 second
  • print(x)shows x in the serial pane
